## Display — AXS15231B QSPI (SPI2 host)

| Signal    | GPIO | Notes                              |
|-----------|------|------------------------------------|
| SCLK      | 5    | QSPI clock                        |
| D0 (MOSI) | 1    | QSPI data line 0                  |
| D1        | 2    | QSPI data line 1                  |
| D2        | 3    | QSPI data line 2                  |
| D3        | 4    | QSPI data line 3                  |
| CS        | 12   | Chip select (active low)           |
| RST       | N/C  | Reset not wired on 3.5B            |
| BL        | 6    | Backlight — LEDC PWM, 5 kHz, 10-bit duty (LEDC_TIMER_0 / LEDC_CHANNEL_0) |

Pixel clock: 40 MHz · Resolution: 320 × 480 · Colour: RGB565

## Touch — AXS15231B integrated capacitive (I2C)

| Signal | GPIO | Notes                                   |
|--------|------|-----------------------------------------|
| SDA    | 8    | Shared I2C0 bus                         |
| SCL    | 7    | Shared I2C0 bus                         |
| INT    | N/C  | Interrupt not wired — polled in firmware |
| RST    | N/C  | Reset not wired                          |

I2C address: `0x3B` · Bus speed: 400 kHz

Touch read protocol: send 11-byte command `{0xb5, 0xab, 0xa5, 0x5a, 0x00, 0x00,
0x00, 0x0e, 0x00, 0x00, 0x00}`, receive 14 bytes.
Byte layout: `[1]` = touch count; points at offsets `[2..5]` and `[8..11]`;
x = `(data[n] & 0x0F) << 8 | data[n+1]`, y = `(data[n+2] & 0x0F) << 8 | data[n+3]`.

---

## I2C0 Bus (shared — SDA GPIO 8, SCL GPIO 7)

| Device    | I2C Address | Component                          |
|-----------|-------------|------------------------------------|
| AXS15231B | 0x3B        | Touch controller (integrated with LCD) |
| QMI8658   | 0x6A / 0x6B | 6-axis IMU (accel + gyro)          |
| PCF85063  | 0x51        | RTC                                |
| AXP2101   | 0x34        | PMIC (power management)            |
| ES8311    | 0x18        | Audio codec                        |

> **Note:** All five devices share I2C0. Use a mutex when accessing from multiple
> tasks (see `board_adapter.cpp` and future service layer). ESP-IDF new I2C master
> driver (`i2c_master_bus_add_device`) handles concurrent access safely if the
> bus handle is shared correctly.

## SD Card — SDMMC (1-bit mode)

| Signal | GPIO | Notes                          |
|--------|------|--------------------------------|
| CLK    | 11   | SDMMC clock                   |
| CMD    | 10   | SDMMC command                 |
| D0     | 9    | SDMMC data line 0 (1-bit mode) |
| CD     | N/C  | Card detect not wired          |
| WP     | N/C  | Write protect not wired        |

Mount point: `/sdcard` · 1-bit SDMMC · Internal pull-ups enabled
(external 10 kΩ pull-ups recommended per Waveshare BSP comment).

| D5/Y7  | 40   |                          |

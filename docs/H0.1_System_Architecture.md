# H0.1 System Architecture

## Display subsystem
- Controller: AXS15231B (QSPI, 4-data-line SPI)
- Board: Waveshare ESP32-S3-Touch-LCD-3.5B
- Resolution: 320 × 480, RGB565 (16-bit)
- LVGL draw buffer: 1/10 frame (320 × 48 pixels) allocated from SPIRAM

## Touch subsystem
- Controller: AXS15231B integrated capacitive touch (I2C address 0x3B)
- Shares I2C bus with IMU (QMI8658), RTC (PCF85063), PMIC (AXP2101)

## Power
- PMIC: AXP2101 (I2C)
- Battery: 3.7 V MX1.25 lithium; dual 18650 via Foriot holder (electrical validation required)

## Initialisation order (board_adapter.cpp)
1. SPI2 bus (QSPI, 40 MHz)
2. Panel IO → AXS15231B panel driver (custom init-command table from Waveshare BSP)
3. I2C0 bus (SDA GPIO 8, SCL GPIO 7, 400 kHz)
4. LVGL display registration + SPIRAM draw buffer
5. LVGL touch indev (polled, raw I2C)
6. Backlight LEDC PWM (GPIO 6, 5 kHz, 50 % duty)

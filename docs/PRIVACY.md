# Privacy principles

Local-first by default. No cloud account, implicit telemetry or network upload. Identifier masking in the UI supports configurable 1–15 leading characters for SSID, MAC/BSSID, BLE identifiers, IPv4, and RFID/NFC. A visible privacy indicator and synthetic preview are required. Raw logs, if later implemented, remain locally stored and may contain sensitive identifiers; exports require explicit user action and warnings. Demo data is synthetic. Do not mistake UI masking for encryption or anonymization of saved data.

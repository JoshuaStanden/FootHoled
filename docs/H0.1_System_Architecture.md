# H0.1 System Architecture

> **Target: Waveshare ESP32-S3-Touch-LCD-3.5 (NON-B).** ST7796 SPI display,
> FT6336 I2C touch, TCA9554 I2C expander for reset/backlight.

## Display subsystem
- Controller: **ST7796** (standard SPI, single data line + DC/CS)
- Board: Waveshare ESP32-S3-Touch-LCD-3.5 (non-B)
- Resolution: 320 × 480, RGB565 (16-bit); colour inversion ON, BGR order (defaults, verify on HW)
- Driver: `espressif/esp_lcd_st7796` component (stock init table — no proprietary vendor table needed, unlike the 3.5B's AXS15231B)
- LVGL draw buffer: 1/10 frame (320 × 48 pixels) allocated from SPIRAM

## Touch subsystem
- Controller: **FT6336** capacitive touch (I2C address 0x38)
- Protocol: standard FT6x36 register read (write reg 0x02, read 5 bytes) — a plain register device, not a proprietary command sequence
- Shares I2C bus with IMU (QMI8658), RTC (PCF85063), PMIC (AXP2101), expander (TCA9554)

## I/O expander
- A **TCA9554** exists on the board (PWR-button EXIO, some peripheral control)
- **Not used by this firmware** — the vendor display/touch path does not need it

## Power
- PMIC: AXP2101 (I2C)
- Battery: 3.7 V MX1.25 lithium; dual 18650 via Foriot holder (electrical validation required)

## Initialisation order (board_adapter.cpp) — mirrors the vendor ESP-IDF port
1. SPI2 bus (standard SPI, 80 MHz pixel clock)
2. Panel IO (SPI, DC=GPIO3, CS=NC)
3. ST7796 panel driver (stock init), reset → init → **invert colour ON** → off-until-ready
4. I2C0 bus (SDA GPIO8, SCL GPIO7, 400 kHz) + FT6336 touch device (0x38)
5. LVGL display registration + SPIRAM draw buffers + async flush via trans-done callback
6. LVGL touch indev (polled FT6336 register read)
7. Backlight (LEDC PWM on GPIO6, timer 1), then display on

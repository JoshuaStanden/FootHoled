# Project vision

**FootHoled — Recon. Analyze. Expand.**

FootHoled H1 is a modular, portable, privacy-conscious ESP32-S3 cybersecurity research and diagnostics platform. It is intended for authorized wireless observation, protocol learning, field diagnostics, and experimentation with replaceable hardware modules. The standard edition is intended to be open source; DEF CON-exclusive art, PCB artwork and enclosures remain proprietary.

**Recon** acquires observations from enabled interfaces. **Analyze** organizes, compares, and interprets local observations. **Expand** detects, configures, tests, and initializes hardware modules and, later, third-party programs.

## Long-term vision
- 320×480 capacitive touchscreen with LVGL 9 UI
- Wireless and sensor modules behind stable service interfaces
- GNSS-assisted observations and local analysis, with granular privacy controls
- Battery/current monitoring, SD storage and configurable identifier masking
- 12-pin expansion interface (pinout not finalized)
- SD-based third-party programs through a versioned, sandboxed API (runtime not selected)
- No account, cloud requirement, or implicit telemetry

**Status:** H1 UI alpha / hardware integration incomplete. The project does not yet claim functional RF, RFID, GNSS or IR operations.
